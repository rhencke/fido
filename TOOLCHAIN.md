# Toolchain

Everything Fido's guarantees are pinned to, and how to verify it. This document owns external identities and
adequacy evidence only. It defines no Go meaning and proves no compiler correct.

## Target

```text
GOOS=linux  GOARCH=amd64  GOAMD64=v1  CGO_ENABLED=0
int / uint  pinned 64-bit and DISTINCT from int64 / uint64
```

**No other platform is covered.** Adding one requires a pinned distribution, its own probe profile, adequacy
fixtures and a proof-impact review — see `DECISIONS.md`.

## Pinned identities

Every base image is digest-pinned; every package version is exact. A withdrawn version fails the build loudly
rather than drifting.

accepted semantic target stays Go 1.23 on `linux/amd64` with `GOAMD64=v1` (see Target above).

## Closed build environment

The e2e exports the complete environment so no case inherits host configuration:

```text
GOWORK=off  GOTOOLCHAIN=local  GOPROXY=off  GOENV=off  GOFLAGS=  GOSUMDB=off
GO111MODULE=on  GOOS=linux  GOARCH=amd64      umask 022
```

Project Python runs only inside the pinned container. The host needs shell, Make, Git, Docker and Buildx.

## Observation tuple

External adequacy is judged on exactly:

```text
(stdout bytes, stderr projection, exit status)
```

`println` writes to stderr under this target. A fatal panic is exit status `2` with first line
`panic: <value>`. Traceback and other runtime noise are excluded from every claim and may serve only as
pinned-toolchain evidence.

## Verification commands

```text
make check       gates + pinned-Rocq proof + pinned-Go whole-tree e2e + working-tree generated byte-compare
make prove       dune build + module coverage + layer-dependency gate + whole-theory assumption audit + self-tests
make e2e         emit + pristine generated-module + go build ./... + differentials + witness vs goldens
make regenerate  rebuild and publish the canonical module through the sink, after a validated fresh build
make regen-guard proves `sync` is unbuildable when the fresh build fails
make audit-fresh forces the proof gate and e2e to RUN rather than report a Buildx cache hit
make perf        one serial diagnostic timing, cold and hot, into `.review/PERFORMANCE.tsv`
```

Host Rocq is not supported. Everything runs through Buildx against the pins above.
