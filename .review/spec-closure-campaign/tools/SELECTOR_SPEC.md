# FIDO — Selector Specification (campaign tools reference; matches generate_fixed_point_manifest.py)
Binding minimums from directive v12, plus two rules discovered by execution on 2026-07-24:
**Transcription:** escaped backticks (\`) are literal; **plain enclosing backticks are Markdown formatting and are stripped per marker/selector, never across an anchored pair**; the anchored separator is exactly space-ellipsis-space (` … `); `A → B` = baseline/terminal paths; single path = both; `—` = empty selector (whole-file only).
**Kinds:** `whole-file` raw bytes, coexists with nothing content-level · `markdown-section` unique heading-prefix line through the line before the next heading of ≤ level · `anchored-region` unique start/end markers, inclusive; single-line = identical markers · `table-row` keyed row (closure CSV key `id`; latitude TSV key `latitude_id`), projection `named-fields {…}` in listed order, LF-normalized, `key=value` lines · `json-pointer` RFC 6901 on canonical JSON; projection `key-presence` · `python-symbol` AST top-level def/class/assignment incl. decorators + preceding comment block.
**Projection kinds (closed):** raw-bytes · normalized-section-text · anchored-normalized-text · named-fields · key-presence · header-row.
**Orthogonality (closed list):** file-property:* ⟂ semantic selectors; table-schema ⟂ table-row/field on existing fields; whole-file ⟂ nothing; anchored-region ⟂̸ markdown-section where spans intersect. Union of content selections must equal the structural diff: no uncovered change, no double ownership.
