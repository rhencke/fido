# 3. Blocking finding A — the surviving-code checker still has a false green

## 3.1 Contract violated

This violates:

- M1 strict scope: no surviving declaration, body, theorem statement, constructor, or proof may change;
- M1-10: no surviving Rocq declaration or proof changes;
- M1-12: the checker’s controls and root helpers must be load-bearing;
- M1-14: proof and artifact preservation must be exact;
- the accepted review basis, which requires exact surviving Rocq command equality.

## 3.2 Root cause

`tools/source-diet.py:declaration_blocks` treats every non-declaration command after a declaration as part of that
declaration until another declaration or a proof terminator appears.

That is not a Rocq declaration boundary.

It lets a ledgered dead declaration absorb unrelated commands such as:

```text
Arguments
Hint
Opaque
Transparent
Existing Instance
Section
End
Import
Export
Open Scope
Close Scope
Set
Unset
```

Deleting the declaration and those unrelated commands then passes as one “complete ledgered removal.”

## 3.3 Independently reproduced false greens

The current checker accepts this:

Baseline:

```coq
Definition dead : nat := 0.
Hint Resolve Nat.eq_refl.
Definition live : nat := 1.
```

Candidate:

```coq
Definition live : nat := 1.
```

Ledger:

```text
Root.v  definition  dead  no-current-consumer  ...
```

Current result:

```text
1 .v file(s): every surviving declaration identical, 1 complete ledgered removal(s)
```

The same false green was reproduced with:

```coq
Arguments dead.
Opaque Nat.add.
Section S. ... End S.
```

The unrelated command disappears with `dead`, and the checker still reports exact surviving code.

The current tree’s eight deletions appear consistent with whole declaration removals. This finding does not claim
that one of those eight actually changed semantics. It means the acceptance evidence cannot establish M1-10.

## 3.4 Required repair

Replace the current declaration grouping with a fail-closed top-level Rocq command ownership model.

One valid design is:

1. Lex comments and strings exactly as now.
2. Split the file into exact top-level vernacular commands.
3. Classify each command independently.
4. A declaration unit contains:
   - its exact declaration command;
   - only its own proof commands, when that declaration opens a proof;
   - its exact proof terminator.
5. A self-contained declaration with a body does not absorb later commands.
6. Every non-declaration command remains an independent unit.
7. If the scanner cannot decide whether a declaration is self-contained or proof-bearing, fail and name the exact
   file and command. Do not guess.
8. Removing a ledgered declaration removes only that exact declaration unit.
9. The complete remaining command stream must equal the candidate command stream exactly and in order.

At minimum, distinguish:

- theorem-like declarations with a proof from theorem-like term definitions using `:=`;
- `Definition`, `Fixpoint`, `CoFixpoint`, `Instance`, and `Let` with a body from proof-built forms;
- self-contained `Inductive`, `Variant`, `Record`, `Class`, `Axiom`, `Parameter`, `Conjecture`, `Notation`, and
  module declarations;
- independent structural and control commands.

Do not solve this with a hard-coded list of the eight current deletion spans or a post-hoc hash allowlist.
