5. BLOCKING FINDING B — CORE DOES NOT RETAIN THE WHOLE ELABORATION
===============================================================================

The current `Compilable.Core` stores only:

- `phase`

It then defines:

- package refs by calling `program_package_refs`;
- layout by calling `root_layout p`;
- plan by calling `fresh_build_plan_of`;
- raw diagnostics by rebuilding the package/phase projection;
- final diagnostics by calling the command ordering function.

These values may be deterministic functions of retained source objects, but they are not the exact objects built

diagnostic projections. A later equality to a source function is specification, not retained production identity.

-------------------------------------------------------------------------------
5.1 Required Core topology
-------------------------------------------------------------------------------

Use one proof-carrying core equivalent to:

```coq
Record Core (p : Syntax.Program) : Type := make_core {
  input : Input p;
  phase : Phase input;

  package_refs : PackageMap.t (list (Index.DeclRef p));
  package_present : exact domain proof over package_refs;
  package_len : exact bucket-length proof over package_refs;
  package_belongs : exact package-membership proof over package_refs;
  package_refs_from_visit :
    package_refs = program_package_refs_from_visit
                     (index input) (input_visit input);

  layout : PackageMap.t FreshRootEntryKind;
  layout_exact : layout = root_layout p;

  plan : FreshBuildDisposition;
  plan_exact :
    plan = fresh_build_plan_of
             (Syntax.module_spec p)
             (map fst (PackageMap.elements package_refs))
             layout;

  raw_diagnostics : list (DiagnosticReason p);
  raw_diagnostics_exact :
    raw_diagnostics =
      phase_diags phase ++
      bucket_diags_elems package_refs ...;

  diagnostics : list (DiagnosticReason p);
  diagnostics_exact :
    diagnostics =
      command_diagnostics_of p plan
        (bucket_flatten (node_keyed raw_diagnostics)
         ++ package_primary raw_diagnostics)
}.
```

The exact dependent organization may differ.

Required properties:

- `build_elaboration_core` builds input once;
- phase once from that exact input;
- package refs once from that retained visit;
- layout once;
- plan once from the retained package refs and layout;
- raw diagnostics once;
- final diagnostics once;
- all proofs are stored with those exact values;
- no field is replaced by a function which reruns its builder each time;
- no foreign package map, layout, plan, phase, or diagnostics can be paired without the exact coherence evidence.

Source-level equality theorems remain separate specification bridges.
